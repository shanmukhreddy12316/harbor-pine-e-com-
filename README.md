# Harbor & Pine storefront

A responsive sample retail storefront built with beginner-friendly HTML, CSS, and plain JavaScript. No build tools, server, checkout, or customer-data collection are required.

## Open it

Open `index.html` in a current web browser. An internet connection is needed for the Google Fonts and product photography; the page itself is local.

## What’s included

- `index.html` — page sections, navigation, product area, offer, reviews, and footer
- `styles.css` — colors, typography, responsive layouts, and mobile navigation styling
- `script.js` — sample catalog, category filters, search, price sorting, bag count, and demo form feedback

## Interactions

Use the category buttons or image tiles to filter products, search by product name, or sort by price. “Add to bag” updates the bag count and shows a confirmation. The bag is a front-end demo only: it does not save orders or connect to payments. Newsletter forms show a local demo message and do not submit or retain an email address.

Product and editorial photography is loaded from Unsplash; fonts are loaded from Google Fonts. Replace those image URLs with locally hosted assets if you need the site to work offline.
